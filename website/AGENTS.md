# Working on the website

Read [spec/README.md](spec/README.md) before changing website behavior or delivery.
Agents own and maintain `spec/`; update the affected requirements with the implementation.
Keep `README.md` short and useful to a person opening this directory for the first time.

Check specifications against source, configuration, and canonical legal text.
Keep dated validation and deployment evidence in `agent-docs/project/builds/`, rather than appending it to the specification or README.
Follow the repository’s [completion process](../agent-docs/project/committing.md).

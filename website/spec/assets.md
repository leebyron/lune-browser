## Appearance and sources

Follow system appearance: Chlorophyll Daylight (`#E7EDE3`) and Pelagic Signal (`#10354F`) for chrome, with selected tabs `#D6E1D2` / `#2A4C62`. Keep appearance colors in [styles.css](../public/styles.css) and canonical logo geometry/palettes in [branding/](../../branding/README.md), rather than retaining earlier logo-width percentages here.

| Asset | Source and maintenance |
| --- | --- |
| `assets/lune-icon.svg`, `assets/lune-mark.svg`, `favicon.svg`, PNG/ICO/touch fallbacks | Generated by [render-assets.py](../../scripts/branding/render-assets.py) from the shared branding sources. SVGs adapt to appearance; raster favicon/touch fallbacks use the dark tile. |
| `assets/lune-dock-light.png`, `assets/lune-dock-dark.png` | Exports from the Apple-compiled app icons through [render-app-icons.py](../../scripts/branding/render-app-icons.py). Do not add another CSS tile/frame. |
| `assets/wallpaper-light.jpg`, `assets/wallpaper-dark.jpg` | Finished cyanotype treatments shared with onboarding; no runtime tint or wash. `wallpaper.jpg` is retained source/reference artwork. |
| `assets/cotton-paper.jpg` | Generated scan-style cotton-paper texture. Repeat at 768px; Dark uses overlay and Light uses filtered multiply. Keep the texture visual-only and moving with the page. |
| Botanical SVGs | Seeded original artwork generated in [main.js](../public/main.js); no external illustration service. |
| `assets/pen-underline.svg` | Original sketched arc ending in a dot; use only on handwritten links. |

The paper texture was generated with the prompt: “Flatbed-scan style neutral midgray cotton rag drawing paper, fine interwoven cellulose fibers, uniform diffuse illumination, seamless edges, no text, folds, pits or blotches.”

Stamens and pollen use yellow in Light and teal in Dark, with Display P3 colors where supported and sRGB fallbacks. Preserve appearance-specific ink contrast and the shared texture treatment of text and background.

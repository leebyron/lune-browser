# Neutral sidebar groups

The owner accepted this implementation for [issue #30](https://github.com/leebyron/lune-browser/issues/30) on November 11, 2026 and requested adoption for future builds. Signed input `inputs/sidebar-reviewed-1/macos` retains the complete accepted series; its final platform commit is `51acf1cc9d8cb0ec4b6a71e40c4416bb10b93175`. Published browser releases remain unchanged.

Vertical group headers match Older Tabs: semibold tab-label typography, semantic neutral text, compact section height, aligned labels and a hover disclosure. The shared layout centers the title and disclosure in the same header cell. A header occupies 18 px of visible section content with an extended 24 px hit target. Groups have 6 px of leading space unless the preceding visible item is another group, so adjacent groups do not accumulate an extra gap. The accepted effective trailing separation is half a tab height minus 6 px, including the parent row gap: 9 px compact or 12 px comfortable. Collapsed groups keep section separation without phantom tab rows.

There is no ellipsis button, colored header treatment or vertical group bar. Grouped tabs use ordinary row bounds and rendering without extra group indentation. Right-click retains renaming and applicable group operations while omitting the vertical editor's color picker. Null-picker guards preserve rename, external visual-data updates and menu rebuilds; stored group colors and horizontal presentation remain intact. Header keyboard interaction and accessible expand/collapse state remain available, with no invisible editor-button focus target.

The focused styling commit is `3bdafbd1`, adding `helium/ui/neutral-tab-groups.patch`. The remaining commits independently refine Older Tabs animation, weekday headings, disclosure alignment, scroll layout/padding and edge hairlines.

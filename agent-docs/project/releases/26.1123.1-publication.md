# Lune 26.1123.1

Changes since **26.1121.2**.

## New features

- Group selected tabs from the tab menu, the command palette, or **⌘G**. The tab menu also offers to add, move, or remove tabs based on where you click.
- Hover over an Older Tabs row and choose **Keep Tab** to return it to the regular tab list without switching to it.
- Site Information opens in a native macOS popover with clearer connection status and updated icons.
- Picture-in-Picture has native window controls, a glass scrubber, and a mute button.

## Bug fixes

- Restore the last saved session automatically after an unclean exit, without showing a recovery prompt.
- Open the sidebar menu by right-clicking empty space between tabs, or drag there to move the window.
- Show mute actions for tabs that have played audio and hide **Hibernate** for tabs that are already hibernated.
- Match the sidebar toggle to the glass toolbar, give selected tabs a neutral highlight in Native Light, and make hibernated tabs easier to distinguish.

## Engine

Chromium **[159.0.8154.13](https://chromereleases.googleblog.com/2026/11/early-stable-update-for-desktop_01707050408.html)** is unchanged from 26.1121.2. It is ahead of the macOS Stable version reported by Chromium Dash at input selection.

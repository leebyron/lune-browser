# Lune 26.1109.1

Lune is a Chromium browser for macOS, assembled from Helium,
ungoogled-chromium, selected upstream contributions, and Lune's own changes.
This release uses Chromium 158.0.8127.18. Publication and promotion each require
a fresh comparison with the latest macOS Stable release.

The November 9, 2026 check at 21:37 UTC observed macOS Chromium Stable
157.0.8103.51 in [Chromium Dash](https://chromiumdash.appspot.com/fetch_releases?channel=Stable&platform=Mac&num=1).
Lune's Chromium 158.0.8127.18 engine is ahead of that observed Stable version.
The final publication observation is recorded with the production feed.

Separate downloads are provided for Apple silicon (`arm64`) and Intel (`x86_64`),
requiring macOS 13 or newer. The DMGs are signed with Lune's Developer ID,
notarized by Apple, and carry architecture-specific Sparkle update signatures.
Drag Lune to Applications and open it normally. Do not bypass a Gatekeeper warning;
report it instead.

This version brings together the floating native glass controls, vertical tab
sidebar, Command-T search and Helium bangs, refreshed setup, and adaptive Lune
artwork. Setup offers independent consent for automatic browser updates and
optional Helium services. The service provider remains Helium. Native glass uses
an older-system fallback where the current AppKit material is unavailable.

Updates and downloads are hosted by GitHub. Each version keeps immutable DMGs
and corresponding source; the website's permanent download URLs follow the
latest stable release. Sparkle feeds are separate for Apple silicon and Intel.
The Lune release version is distinct from Chromium's engine version.

This release uses the production/stable channel. Signed installation, browsing,
persistence and installed updates pass on Apple silicon and Intel under Rosetta.
At publication, physical Intel testing, including macOS 13, remained pending;
the owner chose to publish and address discovered problems in subsequent versions.
Subsequent owner testing confirmed downloading and using the Intel build on
macOS 13.7.8, but the complete native Intel acceptance matrix remains pending. Acceptance and Chromium freshness observations
accompany the stable feed history. There is no public prerelease or staging step.

## Known issues reported after publication

- Older macOS can show transparent corner gaps because content clipping uses a
  larger radius than its native window frame. Fallback glass controls and Command-T
  can also lack enough edge contrast. Both have source fixes in 26.1109.2.
- The replacement red window button can do nothing. This is fixed in 26.1109.2;
  its fix also corrects a classic-fullscreen teardown fault.
- The Make default browser sidebar item can be absent on macOS 13 even when Lune
  is not the default. Settings > Default browser still offers the action. This
  remains unresolved in 26.1109.2.
- Native resize cursors can still flicker intermittently while Lune is active;
  window resizing remains functional.

These observations do not change the immutable 26.1109.1 binaries. Earlier
Rosetta tests do not establish native Intel acceptance or cover every supported
macOS version.

The matching source kit identifies the exact source commit and includes the
Helium-derived core/platform history, patch provenance, build configuration,
licenses, and pinned dependency archives. Signing credentials are excluded.
Helium, ungoogled-chromium, Chromium, Sparkle, and other bundled projects retain
their original attribution and licenses.

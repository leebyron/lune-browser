# Lune 26.1109.1

Lune's first date-versioned production release brings its new macOS interface to
Apple silicon and Intel: floating controls, vertical tabs, and a command palette
that knows its bangs.

## New features

- **Controls when you need them.** An editable native glass address bar and
  floating navigation controls reveal on hover. The vertical sidebar can stay
  pinned or slide into view, on either side of the window.
- **Command-T, with range.** Open a URL, search, switch tabs, or use Helium bangs
  from a native command palette. Address suggestions and Command-T share clear
  result rows and keyboard navigation.
- **Make it feel like home.** Customize the toolbar and sidebar, choose System
  or Lune appearance presets, and enjoy Lune artwork that follows light and dark.
- **A proper welcome.** Refreshed setup uses packaged artwork and fonts, and
  separates automatic-update consent from optional Helium services. Helium
  remains the service provider.
- **Updates that come to you.** Separate Apple silicon and Intel Sparkle feeds
  deliver signed updates. The website's permanent download links follow the
  latest production release without needing a website deployment each time.

## Fixes and polish

- Refine native toolbar icons, menu interactions, address suggestions and
  Command-T spacing, selection and scrolling.
- Show Lune's own release version in About and version diagnostics, separately
  from Chromium's engine version.
- Keep an older-system material fallback where native glass is unavailable.

## Engine and security

This release uses **Chromium 158.0.8127.18**, with Helium and ungoogled-chromium as
its browser foundations. The November 9 input check at 21:37 UTC observed macOS
Chromium Stable 157.0.8103.51 in [Chromium Dash](https://chromiumdash.appspot.com/fetch_releases?channel=Stable&platform=Mac&num=1).
Lune's engine is ahead of that observation. Fresh publication and promotion
checks are recorded in the production feed history.

## Downloads and testing

Choose the **Apple silicon or Intel DMG** for **macOS 13+**, drag Lune to
Applications, and open it normally. Both DMGs are Developer ID signed,
Apple-notarized, and Sparkle-signed. Immutable downloads, matching source and
checksums are attached below. This is the production channel.

Signed installation, browsing, saved data and installed updates passed on Apple
silicon and Intel under Rosetta before publication. The owner approved publishing
with physical Intel checks pending. Subsequent owner testing confirmed downloading
and using the Intel build on macOS 13.7.8; the complete native Intel acceptance
matrix remains pending.

## Known issues reported after publication

- Older macOS can show transparent corner gaps and low-contrast fallback
  controls or Command-T. Source fixes are included in 26.1109.2.
- The replacement red window button can do nothing. 26.1109.2 fixes it and a
  classic-fullscreen teardown fault.
- The Make default browser sidebar item can be absent on macOS 13 even when
  Lune isn't the default. **Settings > Default browser** still offers the action.
  This remains unresolved in 26.1109.2.
- Native resize cursors can flicker while Lune is active; resizing still works.

These reports do not change the immutable 26.1109.1 binaries. Rosetta checks do
not establish native Intel acceptance or cover every supported macOS version.

bundled projects. The source kit preserves their history, provenance and licenses,

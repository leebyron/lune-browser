# Lune 26.1109.1

First date-versioned production release for Apple silicon and Intel on macOS 13 or newer.

## New features

- Native glass address bar and navigation controls that reveal on hover; vertical sidebar that can be pinned or revealed on either side.
- Command-T palette for URLs, searches, tab switching and Helium bangs, with shared address suggestion rendering and keyboard navigation.
- Customizable toolbar and sidebar, System and Lune appearance presets, and light/dark artwork.
- Refreshed setup with separate consent for automatic updates and optional Helium services. Helium remains the service provider.
- Architecture-specific Sparkle updates and permanent website download links.

## Fixes

- Refine toolbar icons, menus, address suggestions and Command-T layout, selection and scrolling.
- Show Lune and Chromium versions separately in About and version diagnostics.
- Provide a material fallback on older macOS versions.

## Engine and security

Chromium **158.0.8127.18**, based on Helium and ungoogled-chromium. The November 9 input check at 21:37 UTC observed macOS Stable **157.0.8103.51** in [Chromium Dash](https://chromiumdash.appspot.com/fetch_releases?channel=Stable&platform=Mac&num=1); Lune's engine is ahead of that observation. Publication and promotion checks are recorded in the production feed history.

## Installation and testing

Download the Apple silicon or Intel DMG, drag Lune to Applications and open it. Both DMGs are Developer ID signed, Apple-notarized and Sparkle-signed. Checksums are attached. [Exact source](https://github.com/leebyron/lune-browser/tree/v26.1109.1) is public.

Signed installation, browsing, persistence and installed updates passed on Apple silicon and Intel under Rosetta. Publication was approved with physical Intel checks deferred. Subsequent owner testing confirmed downloading and using the Intel build on macOS 13.7.8; the full native Intel acceptance matrix remains pending.

## Known issues

- Older macOS can show transparent corner gaps and low-contrast fallback controls or Command-T. Source fixes are included in 26.1109.2.
- The replacement red window button can fail to close the window. 26.1109.2 fixes this and a classic-fullscreen teardown fault.
- The Make default browser sidebar item can be absent on macOS 13. Settings > Default browser remains available; this is unresolved in 26.1109.2.
- Native resize cursors can flicker while Lune is active; resizing remains functional.

## Repository move

These are the original signed binaries, moved without modification. Their embedded Sparkle URL points to the former `lune-downloads` repository, which is being retired. Use manual downloads until a new build embeds the canonical feed. No compatibility feed or redirect is retained.

The public source preserves Helium, ungoogled-chromium, Chromium, Sparkle and other bundled projects' history, attribution and licenses, plus build configuration and pinned dependency manifests. Signing credentials are excluded.

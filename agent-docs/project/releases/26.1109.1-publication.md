# Lune 26.1109.1

## New features

- Native glass address bar and navigation controls that reveal on hover; vertical sidebar that can be pinned or revealed on either side.
- Command-T palette for URLs, searches, tab switching and Helium bangs, with shared address suggestion rendering and keyboard navigation.
- Customizable toolbar and sidebar, System and Lune appearance presets, and light/dark artwork.
- Refreshed setup with separate consent for automatic updates and optional Helium services. Helium remains the service provider.

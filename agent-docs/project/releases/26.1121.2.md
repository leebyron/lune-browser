# Lune 26.1121.2

Changes since **26.1121.1**.

## New features

- A thin line along the bottom of each tab shows page loading progress, including in pinned and background tabs. You can turn it off under **Appearance and behavior**.

## Bug fixes

- Lune now checks for newer releases even when an update is ready to install. Quitting or choosing **Relaunch to update** installs the newest prepared release.

## Engine

Chromium **159.0.8154.13** matches official macOS Stable at release.

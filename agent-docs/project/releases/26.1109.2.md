# Lune 26.1109.2

This production-channel maintenance release targets Apple silicon and Intel Macs
running macOS 13 or newer. It uses Chromium 158.0.8127.18 and retains Helium and
ungoogled-chromium as its browser foundations. Helium remains the provider of the
optional browser services; browser updates are delivered by Lune through GitHub.

## Changes since 26.1109.1

- Add adaptive hairline edges and soft shadows to older-macOS fallback header
  controls and Command-T. Restore the inherited smaller content corner radius
  before macOS 26 to match the older native frame more closely.
- Fix the red window button and safe closure of classic fullscreen windows,
  preserving unload confirmation and ordinary tab/window close behavior.
- Keep toolbar menus and download-completion menus visible with their header.
  Downloads gain native SF status badges and progress through the original icon ring.
- Float page prompts along the bottom of the content area with consistent spacing,
  hairlines and shadows; allow multiple distinct prompts to stack.
- Remove the macOS Dock-pinning prompt.
- Default startup to Continue where you left off, respecting saved and managed choices.
- Refine unpinned sidebar theme colors and tab selection contrast. Use a shared
  216-point default sidebar width while preserving saved widths.

157.0.8103.51 in [Chromium Dash](https://chromiumdash.appspot.com/fetch_releases?channel=Stable&platform=Mac&num=1).

This version is being prepared. Build, signing, notarization, installed updates,

DMGs, with immutable versioned downloads and permanent latest-download aliases.
The website follows those aliases without a deployment for each browser release.
There is no public staging channel or prerelease step.

## Known limitations

Native resize cursors can still flicker intermittently while Lune is active.
The missing Make default browser sidebar item on the reported macOS 13 install
remains under investigation; Settings > Default browser still offers the action.
That unresolved candidate is not part of these release inputs.

The older-system corner and contrast fixes need visual confirmation on macOS 13.
Native Intel execution of the new combined release remains unverified. Prior
Intel checks under Rosetta do not establish native Intel acceptance. An earlier
release's hardware-test deferral does not supply acceptance for this version.

Corresponding source, exact input identities, patch provenance, build configuration
and licenses will accompany any published binaries. Signing credentials remain
outside the repository and source kit.

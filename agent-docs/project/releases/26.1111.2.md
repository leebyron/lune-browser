# Lune 26.1111.2

Production-channel release for Apple silicon and Intel on macOS 13 or newer.

## New features

- Expand Command-T to 53 commands, including tab groups, media playback, page actions and sidebar controls. Open command search with Cmd-/ or Cmd-Shift-P, or type `/` in Command-T. Commands show their assigned shortcuts and adapt to the current tab and playback state.
- Add search-engine query and website suggestions to Command-T. The shared Search suggestions setting controls both Command-T and the address bar; custom setup requires opt-in, while Use defaults enables suggestions. Private windows do not request Command-T suggestions.
- Suggest installed search bangs in Command-T, with recent and frequent choices ranked higher. Selecting a bang applies its search scope directly.
- Show Helium services changes in a dismissible sidebar notice. Give Helium services updates their own setting and setup control, independent of browser updates.

## Bug fixes

- Prevent side-docked DevTools from revealing or retaining the hover header.
- Keep Customize from adding a temporary toolbar icon when its panel opens.
- Preserve the typed search and selected result when asynchronous suggestions arrive, including explicit search-engine and tab scopes.
- Include Lune and upstream license and attribution files in the installed app.

## Engine and security

The November 11 input check at 10:58 UTC observed macOS Stable **157.0.8103.51** in [Chromium Dash](https://chromiumdash.appspot.com/fetch_releases?channel=Stable&platform=Mac&num=1); Lune's engine is ahead of that observation. Publication and feed promotion require fresh checks.

## Downloads and compatibility

Each release contains one signed, Apple-notarized DMG per architecture. Version-specific and latest-download URLs reference the same file. Sparkle uses the version-specific URL. Drag Lune to Applications and open it normally.

Versions 26.1109.1 and 26.1109.2 embed the former repository's feed URL. Download a current version manually to restore automatic updates after that repository is removed. There is no compatibility redirect.

## Testing and known issues

The owner accepted the included features in development previews. Both development builds and focused command, search, setup and settings checks pass; Intel runtime checks use Rosetta. Frozen builds, signing, notarization and installed-update acceptance are pending for this version and will be recorded separately. Development results do not establish release acceptance or physical Intel verification.

- The Make default browser sidebar item can remain missing on macOS 13. Settings > Default browser remains available.
- Native resize cursors can flicker while Lune is active; resizing remains functional.
- New command and settings messages use English source text; additional translations remain follow-up work.

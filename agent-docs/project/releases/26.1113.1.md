# Lune 26.1113.1

Changes since **26.1111.3**.

## New features

- Add pinned tab groups, native group context menus and inline group naming. Close Tabs in Group replaces the separate Close and Delete actions; closed tabs remain recoverable from History.
- Add separate toolbar hover modes for the page edge and sidebar.
- Update the app icon and Lune artwork with thicker curves and refined glass rendering.

## Bug fixes

- Preserve Command-T and address-field focus and selection when switching apps.
- Use Chromium word boundaries for Option-Arrow navigation and Option-Shift-Arrow selection in Command-T and the address field.
- Keep the toolbar visible while an extension popup is open.
- Prefer the selected search engine in initial search-bang suggestions.
- Restore saved sessions without the informational startup bar.
- Improve selected-tab and group-caret contrast in the Native theme.
- Align a leading emoji in group names with tab favicons and add separators between expanded groups and ungrouped tabs.
- Match the address-field cursor to its editing state.

## Engine

Update Chromium from **158.0.8127.18** to **158.0.8127.37**, including upstream stability and security fixes. Matches the macOS Stable version reported by Chromium Dash on November 13; Google is rolling out this version as early Stable.

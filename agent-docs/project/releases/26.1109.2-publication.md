# Lune 26.1109.2

Tabs that remember where you left off, clearer controls on older Macs, and a red
window button that does its job. This release gives the everyday details some attention.

## New features

- **Pick up where you left off.** New profiles default to restoring the previous
  session. Your existing startup choice—and any managed setting—still wins.
- **Downloads, with a native accent.** Download status uses macOS SF Symbols,
  with progress drawn through the original symbol ring. Toolbar and download
  menus keep the header visible while you're using them.
- **A fresh coat for the sidebar.** The floating sidebar follows the owning
  theme, selected tabs have clearer light/dark contrast, and new sidebars start
  at 216 points wide. Saved widths stay yours.
- **Prompts find their place.** Page prompts float along the bottom of the
  content, with consistent spacing and room for distinct prompts to stack.

## Bug fixes

- Add adaptive hairline edges and soft shadows to fallback header controls and
  Command-T on older macOS versions, so they stand out against busy pages.
- Match older macOS content clipping to the inherited 12-point radius; macOS 26
  and newer retain the 16-point radius. This addresses the reported transparent
  corner gaps without imposing the newer frame shape on older systems.
- Fix the replacement red window button and classic-fullscreen close teardown,
  retaining ordinary tab/window close protections and unload confirmation.
- Remove the macOS Dock-pinning prompt. Your Dock can make its own arrangements.

## Engine and security

Chromium remains **158.0.8127.18**, unchanged from 26.1109.1, along with the Helium
core input. The input-selection check observed macOS Chromium Stable
157.0.8103.51; Lune's engine is ahead of that observation. Publication and feed
promotion each recheck [Chromium Dash](https://chromiumdash.appspot.com/fetch_releases?channel=Stable&platform=Mac&num=1).
The freshness observations accompany the production feed history.

## Downloads and testing

Separate signed, Apple-notarized DMGs support **Apple silicon and Intel on
macOS 13+**. Drag Lune to Applications and open it normally. GitHub hosts the
versioned downloads, permanent latest links, and separate Sparkle feeds. The
website follows the latest links automatically. This is the production channel.

Both frozen builds pass. Signed browsing, saved data, session restoration, and
real local Sparkle updates from 26.1109.1 and build 2 pass on Apple silicon and
Intel under Rosetta; bad signatures and unsupported OS requirements are rejected.
Packaged setup was checked with optional Helium services disabled. Physical Intel
checks and macOS 13 visual confirmation remain pending; the owner approved
publication of these exact artifacts with those checks deferred. Installed public HTTPS updates from 26.1109.1 also pass on both architectures,
including relaunch, saved data and signature checks.

## Still on the list

- The Make default browser sidebar item can remain missing on macOS 13.
  **Settings > Default browser** still offers the action. No fix is claimed here.
- Native resize cursors can still flicker while Lune is active; resizing works.

Lune is built on **Helium, ungoogled-chromium, and Chromium**. Optional browser
services are provided by Helium; browser updates are delivered by Lune through
GitHub. [The exact source](https://github.com/leebyron/lune-browser/tree/v26.1109.2)
is public, including input locks, patch history, build instructions and licenses.
Pinned dependency archives remain available at their recorded URLs and on the
previous release. Validation and checksums accompany these downloads; signing
credentials stay private.

## Repository move

These are the original signed browser files, moved into the Lune source repository
without changing their bytes. Their embedded Sparkle URL still points to the former
`lune-downloads` repository, which is being retired. Use manual downloads for these
builds; a future browser build will embed the new feed URL. No compatibility feed
or redirect is retained.

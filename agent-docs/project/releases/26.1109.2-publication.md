# Lune 26.1109.2

Production release for Apple silicon and Intel on macOS 13 or newer.

## New features

- New profiles restore the previous session by default. Existing and managed startup choices are preserved.
- Download status uses macOS SF Symbols and the existing progress ring. Toolbar and download menus retain the header while open.
- The floating sidebar follows the window theme, with improved selection contrast and a 216-point default width. Saved widths are preserved.
- Page prompts float at the bottom of the content area and support stacking.

## Bug fixes

- Add adaptive hairline edges and soft shadows to fallback header controls and Command-T on older macOS.
- Use the inherited 12-point content radius before macOS 26 to address transparent corner gaps; macOS 26 and newer retain 16 points.
- Fix the replacement red window button and classic-fullscreen close teardown, preserving unload confirmation and ordinary close behavior.
- Remove the macOS Dock-pinning prompt.

## Engine and security

Chromium remains **158.0.8127.18**, unchanged from 26.1109.1, with the same Helium core input. The input-selection check observed macOS Stable **157.0.8103.51**; Lune's engine is ahead of that observation. Publication and feed promotion recheck [Chromium Dash](https://chromiumdash.appspot.com/fetch_releases?channel=Stable&platform=Mac&num=1), with observations recorded in the production feed history.

## Installation and testing

Download the Apple silicon or Intel DMG, drag Lune to Applications and open it. Both DMGs are Developer ID signed, Apple-notarized and Sparkle-signed. GitHub hosts versioned downloads, permanent latest links and separate Sparkle feeds. The website follows the latest links automatically.

Both frozen builds pass. Signed browsing, persistence, session restoration and local Sparkle updates from 26.1109.1 and build 2 pass on Apple silicon and Intel under Rosetta. Invalid signatures and unsupported OS requirements are rejected. Installed public HTTPS updates from 26.1109.1 pass on both architectures, including relaunch and persistence. Setup was checked with optional Helium services disabled.

Physical Intel checks and macOS 13 visual confirmation remain pending. Publication of these exact artifacts was approved with those checks deferred.

## Known issues

- The Make default browser sidebar item can remain missing on macOS 13. Settings > Default browser remains available.
- Native resize cursors can flicker while Lune is active; resizing remains functional.

## Repository move

These are the original signed binaries, moved without modification. Their embedded Sparkle URL points to the former `lune-downloads` repository, which is being retired. Use manual downloads until a new build embeds the canonical feed. No compatibility feed or redirect is retained.

Lune is built on Helium, ungoogled-chromium and Chromium. Optional services are provided by Helium; browser updates are delivered by Lune through GitHub. [Exact source](https://github.com/leebyron/lune-browser/tree/v26.1109.2) is public, including input locks, patch history, build instructions and licenses. Dependency manifests retain their recorded archive URLs. Validation and checksums accompany these downloads; signing credentials remain private.

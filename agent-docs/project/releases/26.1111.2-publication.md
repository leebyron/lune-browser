# Lune 26.1111.2

Changes since **26.1110.1**.

## New features

- Expand Command-T to 53 commands, including tab groups, media playback, page actions and sidebar controls. Open command search with Cmd-/ or Cmd-Shift-P, or type `/` in Command-T. Commands show their assigned shortcuts and adapt to the current tab and playback state.
- Add search-engine query and website suggestions to Command-T. The shared Search suggestions setting controls both Command-T and the address bar; custom setup requires opt-in, while Use defaults enables suggestions. The typed action stays first as suggestions arrive. Private windows do not request Command-T suggestions.
- Add typeahead for installed search bangs in Command-T, with recent and frequent choices ranked higher. Selecting a bang applies its search scope directly.
- Show Helium services changes in a dismissible sidebar notice. Give Helium services updates their own setting and setup control, independent of browser updates.

## Bug fixes

- Prevent side-docked DevTools from revealing or retaining the hover header.
- Keep Customize from adding a temporary toolbar icon when its panel opens.
- Include Lune and upstream license and attribution files in the installed app.

## Engine

Chromium remains **158.0.8127.18**, unchanged from 26.1110.1. The November 11 check at 15:42 UTC observed macOS Stable **157.0.8103.51** in [Chromium Dash](https://chromiumdash.appspot.com/fetch_releases?channel=Stable&platform=Mac&num=1); Lune's engine is ahead of that observation.

# Lune 26.1110.1

Production-channel release for Apple silicon and Intel on macOS 13 or newer.

## New features

- Add Check for Updates… below Import Bookmarks and Settings… in the macOS Lune menu. It opens About Lune with current update status.

## Bug fixes

- Use the `lune-browser` GitHub repository for Sparkle feeds. Both the embedded URL and updater delegate use the canonical endpoint.
- Preserve progress and ready-to-relaunch status when checking again during an update. Show an explanation and Update settings link when updates are off or unavailable.
- Correct the settings disclosure to identify GitHub as the browser-update host. Optional services remain provided by Helium.

## Engine and security

Chromium remains **158.0.8127.18**, unchanged from 26.1109.2, with the same Helium and ungoogled-chromium foundations. The November 10 input check at 09:02 UTC observed macOS Stable **157.0.8103.51** in [Chromium Dash](https://chromiumdash.appspot.com/fetch_releases?channel=Stable&platform=Mac&num=1); Lune's engine is ahead of that observation. Publication and feed promotion require fresh checks.

## Downloads and compatibility

Each release contains one signed, Apple-notarized DMG per architecture. Version-specific and latest-download URLs reference the same file. Sparkle uses the version-specific URL. Drag Lune to Applications and open it normally.

Versions 26.1109.1 and 26.1109.2 embed the former repository's feed URL. Once that repository is deleted, download this version manually to restore automatic updates. There is no compatibility redirect.

## Testing and known issues

The owner accepted the update-menu flow. Both development builds, native menu/updater fixtures and isolated browser UI/settings/persistence checks pass; Intel runtime checks use Rosetta. Frozen builds, signing, notarization and installed-update acceptance are pending for this version. Development results do not establish release acceptance or physical Intel verification.

- The Make default browser sidebar item can remain missing on macOS 13. Settings > Default browser remains available.
- Native resize cursors can flicker while Lune is active; resizing remains functional.

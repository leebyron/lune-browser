# Lune 26.1111.3

Changes since **26.1111.2**.

## New features

- Add Older Tabs: inactive tabs move into dated sections after one day and close after three more inactive days by default. Keep Tab or dragging a tab back restores it to the regular list. Timings and grouped-tab cleanup are configurable; pinned and split tabs are protected.
- Add search-bang scopes to the address bar, with provider pills and recent-use ranking shared with Command-T.
- Restyle sidebar groups as neutral section headers, with animated disclosure, weekday headings for recent Older Tabs, refined spacing and scroll-edge lines.

## Bug fixes

- Keep command-menu glass consistent as the result list changes size.
- Show the startup restore notice only when saved tabs exist.
- Preserve header visibility while dragging the sidebar background.
- Make the sidebar New Tab button open Command-T, then create a tab on a repeated press.
- Open toolbar customization directly from the header menu while keeping sidebar customization separate.
- Limit setup toolbar choices to On hover and Always.

## Engine

Chromium remains **158.0.8127.18**, unchanged from 26.1111.2. The November 11 check at 23:06 PST observed macOS Stable **157.0.8103.79** in [Chromium Dash](https://chromiumdash.appspot.com/fetch_releases?channel=Stable&platform=Mac&num=1); Lune's engine is ahead of that observation.

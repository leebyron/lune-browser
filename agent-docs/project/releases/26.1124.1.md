# Lune 26.1124.1

Changes since 26.1123.1.

## New features

- Move the toggle for a right-aligned sidebar into a separate glass button in the toolbar so the sidebar can use its full height.

## Bug fixes

- Fade the sidebar toggle with the toolbar. Edge hover now uses a narrower strip at the top of the window, and sidebar hover also works just above the sidebar header.
- Keep the toolbar visible while the Site Information popover is open.
- Link to Chromium, ungoogled-chromium, Helium, and the full open source credits from About Lune.

## Engine

Chromium 159.0.8154.13 is unchanged from 26.1123.1. It is ahead of the macOS Stable version reported by Chromium Dash at input selection.

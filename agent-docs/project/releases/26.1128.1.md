# Lune 26.1128.1

Changes since 26.1125.1.

## New features

- Import data and saved tabs from individual browser profiles during Setup, with guidance for granting macOS access.
- Open native Back, Forward, and Reload menus with a right-click, Control-click, or press and hold. The Reload menu shows keyboard shortcuts.
- Choose the sidebar font size independently of interface size, and find sidebar and toolbar controls together in Appearance.

## Bug fixes

- Keep the Command-T menu shadow steady as results appear and disappear. Use a softer frosted background with the browser theme tint.
- Open new tabs next to the active tab when adjacent placement is selected, and reset the sidebar width when the interface size changes.
- Place Customize Toolbar directly below Customize New Tab, and refine the Setup Services and password-manager descriptions.

## Engine

Chromium [159.0.8154.34](https://chromereleases.googleblog.com/2026/11/early-stable-update-for-desktop_027920431.html) matches the macOS Stable version reported by Chromium Dash at input selection.

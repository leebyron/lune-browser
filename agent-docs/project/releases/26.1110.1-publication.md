# Lune 26.1110.1

## New features

- Add Check for Updates… below Import Bookmarks and Settings… in the macOS Lune menu. It opens About Lune with current update status.

## Bug fixes

- Use the `lune-browser` GitHub repository for Sparkle feeds. Both the embedded URL and updater delegate use the canonical endpoint.
- Preserve progress and ready-to-relaunch status when checking again during an update. Show an explanation and Update settings link when updates are off or unavailable.
- Correct the settings disclosure to identify GitHub as the browser-update host. Optional services remain provided by Helium.

## Engine

Chromium remains **158.0.8127.18**, unchanged from 26.1109.2, with the same Helium and ungoogled-chromium foundations. The November 10 publication and promotion checks at 15:02 UTC observed macOS Stable **157.0.8103.51** in [Chromium Dash](https://chromiumdash.appspot.com/fetch_releases?channel=Stable&platform=Mac&num=1); Lune's engine is ahead of that observation.

# Lune 26.1119.1

Changes since **26.1115.1**.

## New features

- Drag a window from empty space at the top of a webpage. This is on by default and can be turned off in Appearance and behavior.
- Open eligible videos in Picture-in-Picture automatically when you switch tabs. The player uses new macOS window and playback controls.
- Remove known tracking parameters from supported links when opening or copying them. Setup includes a Privacy step for configuring this behavior.
- Set the tab order for Control-Tab and Command-Shift-bracket independently. The bracket shortcuts now follow sidebar order by default.
- Drag tabs between pinned tiles, tab groups and the regular sidebar list. Sidebar drag-and-drop now gives haptic feedback on supported trackpads.

## Bug fixes

- Stabilize sidebar drop targets and group highlights as tabs move, pin and unpin.
- Improve sidebar and toolbar reveal near window edges. The toolbar now opens within 8 points inside the top edge, and the sidebar stays hidden during webpage fullscreen.
- Restore pointer input in DevTools docked to either side of a window using Always Show Toolbar.
- Cap the width of the address bar and Command-T menu in wide windows.
- Improve notification contrast in native light and dark appearances.

## Engine

Chromium **158.0.8127.37** is unchanged from 26.1115.1. Upstream Stable freshness was skipped for this release.

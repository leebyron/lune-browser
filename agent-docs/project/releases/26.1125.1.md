# Lune 26.1125.1

Changes since 26.1124.1.

## New features

- Choose a custom browser color in Customize Lune or during Setup. The color wheel previews your changes and supports undo, redo, and restoring the original color.
- Downloads opens in a native macOS popover with file icons, download controls, and a shortcut to Show All Downloads.
- Manage wallpaper and shortcuts in Customize Lune alongside the built-in New Tab page.

## Bug fixes

- Refine hover, drag reordering, and address-bar focus in the floating glass toolbar. Give the Command-T palette a softer shadow.
- Center the initial browser window and size it to fit the available screen area.
- Refine Site Information, the download-start and opening indicators, and the icons in Setup and the Link copied confirmation.

## Engine

Update Chromium to 159.0.8154.34, matching the macOS Stable version reported by Chromium Dash at input selection.

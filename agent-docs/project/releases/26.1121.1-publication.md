# Lune 26.1121.1

Changes since **26.1119.1**.

## New features

- Picture-in-Picture fades out its controls after 2.5 seconds. When Lune is active, the pointer also hides over the video. Moving it brings the controls back.
- The first manual Picture-in-Picture session on a site offers to open it automatically when you switch tabs.
- Comfortable sidebar density uses wider spacing and a wider default sidebar. Pinned tabs are taller, and the sidebar can reveal from the top edge.
- The Dock icon follows the browser’s light or dark appearance, and the Lune icon has an updated gradient.

## Bug fixes

- Show native tab-status symbols and matching hover cards for audio, Picture-in-Picture, recording, sharing, and connected devices.
- Show the sidebar scrollbar during manual scrolling, improve pinned-tab drag positioning, and align Older Tabs date headers.
- Allow window dragging from more page-top areas and align spacing in nested Settings rows.

## Engine

Chromium **[159.0.8154.13](https://chromereleases.googleblog.com/2026/11/early-stable-update-for-desktop_01707050408.html)** matches official macOS Stable at release. Lune also incorporates Helium **0.22.2**.

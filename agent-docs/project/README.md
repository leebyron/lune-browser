# Lune project guide

Lune combines ungoogled-chromium, Helium and selected upstream and local features. Arc is an interaction-design reference. Keep reusable browser features independent of Lune's identity, services and release infrastructure.

- [AGENTS.md](../../AGENTS.md) routes work to the relevant runbook.
- [Project state](status.md) points to current manifests, releases and open issues.
- [Architecture](architecture.md) describes component histories and patch integration.
- [Roadmap](roadmap.md) lists deferred work. [Research](research.md) and [the Xelium integration record](xelium-ui.md) are dated source investigations.

Lune-authored work is GPL-3.0-or-later where otherwise unspecified. Preserve the applicable [license and attribution notices](../../NOTICE) for imported work.
